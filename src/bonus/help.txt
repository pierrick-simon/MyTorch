USAGE
    ./my_torch_bonus [--train | --eval] TASK FILE [--iteration N]

DESCRIPTION
    --train     Train the neural network FILE on TASK and save it.
    --eval      Evaluate the neural network FILE on TASK.
    TASK        Name of a truth table: and, xor, hamming.
    FILE        Neural network file (.nn).
    --iteration Number of iterations N (default: 100000 for --train, 1000 for --eval).
